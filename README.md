# Pybricks Robot Control

Программа управления роботом на **LEGO SPIKE Prime Hub** с использованием Pybricks.

Проект разделён на конфигурацию, инициализацию оборудования, PID-настройки, основные функции управления и автономные программы.

## 1. Структура проекта

```text
project/
├── config.py
├── init.py
├── pid.py
├── main.py
└── run.py
```

| Файл | Назначение |
|---|---|
| `config.py` | Порты, направления моторов и параметры робота |
| `init.py` | Подключение и инициализация оборудования |
| `pid.py` | Настройка PID-регуляторов |
| `main.py` | Основные функции движения и управления механизмами |
| `run.py` | Автономные программы и меню выбора |

## 2. Настройка конфигурации

Все основные параметры находятся в `config.py`.

### Порты

```python
LEFT_PORT = "A"
RIGHT_PORT = "B"
MECH_1_PORT = "C"
MECH_2_PORT = "D"
LIGHT_1_PORT = "E"
LIGHT_2_PORT = "F"
```

Допустимые значения: `"A"`, `"B"`, `"C"`, `"D"`, `"E"`, `"F"`.

### Направления моторов

```python
LEFT_DIRECTION = "CCW"
RIGHT_DIRECTION = "CW"
MECH_1_DIRECTION = "CW"
MECH_2_DIRECTION = "CW"
```

- `"CW"` — Clockwise, по часовой стрелке.
- `"CCW"` — Counterclockwise, против часовой стрелки.

Направление задаёт, какое вращение мотора считается положительным. Настройте его так, чтобы положительное движение колёс соответствовало движению робота вперёд.

### Геометрия и скорость

```python
WHEEL_DIAMETER = 56
AXLE_TRACK = 120

DRIVE_SPEED = 400
DRIVE_ACCELERATION = 600

TURN_RATE = 180
TURN_ACCELERATION = 360

MECH_SPEED = 400
```

- `WHEEL_DIAMETER` — диаметр колеса в миллиметрах.
- `AXLE_TRACK` — расстояние между колёсами в миллиметрах.
- `DRIVE_SPEED` — скорость движения в мм/с.
- `DRIVE_ACCELERATION` — ускорение движения в мм/с².
- `TURN_RATE` — скорость поворота в градусах/с.
- `TURN_ACCELERATION` — угловое ускорение в градусах/с².
- `MECH_SPEED` — скорость механизмов в градусах/с.

## 3. Основные функции

Все функции управления находятся в `main.py`.

### Движение

```python
drive(50)
drive(-30)
forward(40)
backward(20)
```

Расстояния задаются в сантиметрах.

- `drive(50)` — движение вперёд на 50 см.
- `drive(-30)` — движение назад на 30 см.
- `forward(40)` — движение вперёд.
- `backward(20)` — движение назад.

Можно указать скорость:

```python
drive(50, 300)
```

### Повороты

```python
turn(90)
turn(-90)
turn_right(90)
turn_left(45)
```

Углы задаются в градусах.

- Положительный угол — поворот в одну сторону.
- Отрицательный угол — в противоположную.
- `turn_right()` и `turn_left()` — удобные функции для поворотов.

Фактическое соответствие положительного угла правому или левому повороту нужно проверить на роботе.

### Механизмы

```python
mechanism1(180)
mechanism2(-90)
```

Моторы поворачиваются на указанное количество градусов относительно текущего положения.

Для перемещения в конкретную позицию:

```python
mechanism1_to(180)
mechanism2_to(90)
```

Другие функции:

```python
reset_mechanisms()
stop_mechanisms()
mechanism_positions()
```

- `reset_mechanisms()` — сброс углов механизмов в ноль.
- `stop_mechanisms()` — остановка моторов механизмов.
- `mechanism_positions()` — получение текущих углов обоих моторов.

### Состояние робота

```python
get_distance()
get_heading()
drive_reset()
stop()
stop_all()
reset_all()
calibration()
```

| Функция | Назначение |
|---|---|
| `get_distance()` | Пройденное расстояние в см |
| `get_heading()` | Текущий угол робота |
| `drive_reset()` | Сброс показаний DriveBase |
| `stop()` | Остановка движения |
| `stop_all()` | Остановка всех моторов |
| `reset_all()` | Сброс показаний движения и механизмов |
| `calibration()` | Вывод параметров и показаний в консоль |

## 4. PID-регуляторы

PID-функции находятся в `pid.py`.

```python
set_drive_pid(kp, ki, kd)
set_turn_pid(kp, ki, kd)
```

- `kp` — пропорциональная составляющая.
- `ki` — интегральная составляющая.
- `kd` — дифференциальная составляющая.

Пример:

```python
set_drive_pid(1.2, 0.01, 0.1)
set_turn_pid(2.0, 0.02, 0.15)
```

Для получения текущих параметров:

```python
get_drive_pid()
get_turn_pid()
print_pid()
```

Значения PID необходимо подбирать экспериментально. Не переносите параметры с другого робота без проверки.

## 5. Автономные программы

Все автономные сценарии находятся в `run.py`.

Каждый сценарий оформляется как отдельная функция:

```python
def run_1():
    drive(50, 300)
    turn(90)
    mechanism1(180)
    drive(30, 400)
```

Добавить новую программу можно следующим образом:

```python
def run_4():
    drive(60)
    turn(-90)
    mechanism2(180)
```

После этого добавьте её в список:

```python
RUNS = [
    ("RUN 1", run_1),
    ("RUN 2", run_2),
    ("RUN 3", run_3),
    ("RUN 4", run_4)
]
```

## 6. Меню на Hub

После запуска `run.py` появляется меню выбора автономной программы.

Управление:

- **Короткое нажатие центральной кнопки** — переключение программы.
- **Долгое нажатие центральной кнопки** — запуск выбранной программы.

Во время выполнения программы индикатор меняет цвет. После завершения на дисплее появляется `DONE`.

Для добавления или удаления программ изменяйте список `RUNS`.

## 7. Порядок запуска

1. Подключите моторы и датчики к указанным портам.
2. Проверьте настройки в `config.py`.
3. Установите корректные направления вращения моторов.
4. Проверьте диаметр колёс и расстояние между ними.
5. Запустите `run.py`.
6. Проверьте движение на небольших расстояниях и поворотах.
7. Настройте PID-регуляторы.
8. Добавьте автономные сценарии.

## 8. Важные замечания

- Все расстояния движения в `main.py` задаются в сантиметрах.
- Все углы поворота задаются в градусах.
- Расстояния в `DriveBase` внутри Pybricks обрабатываются в миллиметрах.
- Скорости движения задаются в мм/с.
- Углы механизмов задаются в градусах.
- Отрицательное расстояние означает движение назад.
- Отрицательный угол поворота означает поворот в противоположную сторону.
- Перед запуском автономной программы убедитесь, что робот находится в правильной стартовой позиции.

**Главный принцип проекта:** конфигурация оборудования меняется в `config.py`, функции управления — в `main.py`, а последовательность автономных действий — в `run.py`.
